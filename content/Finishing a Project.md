Finishing a project can be very important. It provides a satisfaction and relieves us from mental load of an unfinished project. Below are a few strategies that can be helpful to guide and motivate us to finish a project.

1. Define "*Done*" in writing or record before starting the project.
2. Embrace the "*Good Enough* " rather than chasing perfection. Perfection is another way of saying never ending.
3. Set deadlines and time block a project based on the MVP defined previously.
4. Practice finishing by doing small projects...
5. Separate ideation from implementation
6. Celebrate Finishes
7. Embrace Accountability
