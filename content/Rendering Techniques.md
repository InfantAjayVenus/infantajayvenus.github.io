1. Static Website
2. Multi-Page App (MPA)
	1. Pages are dynamically generated from the Server
3. Single Page App (SPA)
	1. The whole page is generated by JS in the client
4. Server Side Rendering with Hydration (SSR)
	1. The initial Request is rendered in Server, followed by JS taking over in the client
5. Static Site Generation (SSG)
	1. Pre-Render all HTML and serve statically, followed by JS taking over in the client
 6. Increment Static Regeneration (ISR)
	 1. Similar to SSG but the generated sites are invalidated and rerendered based on preset conditions
 7. Partial Hydration
	 1. JS takes over only when needed by lazy loading
 8. Islands
	 1. JS is injected only for components that need interactivity other parts remain as static HTML
  9. Stream SSR
  10. Resumability
