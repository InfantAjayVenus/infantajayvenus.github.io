F.I.R.S.T. Principles introduced by Robert C. Martin, are a set of guidelines that help write better tests.
1. *Fast:* Should run quick so as to add productivity
2. *Independent:* Should be isolated
3. *Repeatable:* Able to be run repeatably and be consistent
4. *Self-Validating:* Able to run without manual intervention
5. *Thorough:* Should cover all areas of the system
