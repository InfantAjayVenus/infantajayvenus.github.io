Red, Green, Refactor or *The Boys Scout Rule* is a variation / addition to the [[Three Laws of TDD]]. It provides a set of actions to follow the three laws.
1. **Red**: Write a failing test case
2. **Green**: Write a minimum viable code to pass the test case and commit
3. **Refactor**: Clean up the code and make a separate commit
4. Repeat till the desired work is done.
